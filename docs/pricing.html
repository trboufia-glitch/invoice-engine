So why would anyone pay?

Honestly — most people who need this once a month should not. Paying is for you if:

  • You process invoices automatically, not by hand
  • You want a check on every export before it reaches the ledger
  • You need it to fail loudly — exit non-zero — instead of returning JSON
  • You're feeding a month-end close where a silent error is expensive

Or just take the whole thing

The engine is pure JavaScript with no dependencies. Run it yourself, forever, with no account anywhere.

npm install invoice-normalize

const { normalize } = require('invoice-normalize');
const r = normalize(csvText, { format: 'csv' });

if (r.summary.errors) {
console.error(`${r.summary.errors} rows do not reconcile`);
process.exit(1);
}

MIT-licensed. No telemetry, no calls home, no account required.

Why is the browser version free and unlimited? Because running it costs me nothing — your file is processed by your own CPU, not my server. I'd rather give away the thing that gets people to trust the output than meter something that costs me zero to serve.
